# 第三轮知识准备路线

[返回任务说明](README.md)

本文件记录后续教学顺序，各项学习与操作均待开始。路线按用户已有 Python 基础安排，实际推进时根据理解情况调整。

| 顺序 | 配合任务补齐的知识 | 后续理解检查 |
| --- | --- | --- |
| 1 | 关系数据库、表、行、列、主键、外键、schema | 能解释一张表表达什么，以及两张表如何关联 |
| 2 | SQL 的 SELECT、WHERE、聚合、GROUP BY、ORDER BY、JOIN | 能把小例子的自然语言问题对应到查询步骤 |
| 3 | Text-to-SQL 的输入、输出、标准答案与执行结果 | 能说明模型获得哪些信息，以及如何检查生成结果 |
| 4 | Spider 与 Dr.Spider、扰动、鲁棒性、配对样本 | 能解释一个样例变化了什么，以及变化会带来什么困难 |
| 5 | JSON、SQLite、数据文件与样本标识 | 能找到问题、数据库、表结构和对应 SQL |
| 6 | baseline、实验设置、指标、分组统计与复现 | 能解释实验表每一列的含义和结果的来源 |
| 7 | 问题分类与错误分析 | 能用真实样例支持分类，说明预测与目标之间的差异 |
| 8 | Agent、工具调用、状态、反馈与多 Agent 协作 | 能结合实际代码解释一次请求如何形成 SQL |
| 9 | rsi-data-visual 代码阅读与开发入口 | 能沿入口跟踪数据、模型调用、Agent 消息和输出 |

前七步主要服务于数据集分析和基线实验，第八、九步结合 rsi-data-visual 可获取的代码推进。进入对应环节时再学习环境安装、包管理和项目依赖。

## 第一个实验表需要理解的内容

后续讲清模型与版本、数据版本、样本范围、扰动类型、样本量、评测指标、扰动前后结果和差异。具体列名与汇总方式随基线和官方评测协议确定，填表时使用可追溯的真实结果。

需要能够解释以下问题。

- 该行测量了什么，包含哪些样本。
- 该指标如何计算，分母包含哪些样本。
- 扰动前后如何配对，比较是否使用一致设置。
- 分类平均和全部样本平均分别如何计算。
- 报错、超时、空输出和无法评测的样本如何按协议记录。

## 每次指导的节奏

1. 给出一个小例子并逐步解释。
2. 用户复述或完成一个小练习，核对理解。
3. 进入对应数据或代码，完成一个可观察的步骤。
4. 记录实际输出和仍有疑问的知识点，再推进下一步。

后续第一课围绕“一个问题怎样变成 SQL”展开，再过渡到 Dr.Spider 的样本结构。当前准备阶段结束于任务说明和路线整理。
