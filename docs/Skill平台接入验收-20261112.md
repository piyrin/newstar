# 第二次实验平台接入验收

2026 年 11 月 12 日。第二次 Skill 扩容实验已接回第一次的 Web 工作台与 Airflow。

## 直接操作

1. 打开 `http://localhost:8765/skills`。原简历工作台首页也有“第二次实验 · Skill 自主编排”链接。
2. 保留完整需求，选择候选规模和模型，点击“提交到 Airflow”。
3. 在运行区点击 Airflow 链接，观察校验、派发、执行等待、文件核验、发布五个任务。
4. 回工作台查看实际 Skill 图与指标，预览并下载最终 Markdown 和 CSV。
5. 对照原 facts 与六标准核对内容，填写说明并保存复核。历史区提供原三组十次结果。

电脑重启后的启动命令见 `experiments/skill_portal/README.md`。执行桥运行在 Windows 后台，复用原始模型、源码与来源路径，Airflow 等待采用 reschedule。

## 异常与恢复实测

- `integration-negative-20261112` 模拟主机退出。Airflow的文件核验任务重试后失败，发布任务为upstream_failed。
- `integration-partial-negative-20261112` 还保存一份明确标注的诊断附件，实际浏览器预览与下载通过，页面保留失败状态。
- `integration-torn-dag-20261112` 手工构造截断的dag.json及已退出进程状态。真实执行桥恢复后保存失败与原始损坏文件，未知图指标显示为空，执行桥继续在线。通过HTTP下载的原始字节与摘要一致。

上述三项均为明确标注的集成诊断用例，模型调用数为0。它们在全部记录中可查，独立于正式十次测量。Airflow列表中的红色记录可用于讲解异常路径。
