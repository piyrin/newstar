# Skill 实验接入现有工作台与 Airflow

用户已授权补齐前述网页发起、Airflow 执行、产物和十次结果展示链路。本计划使用 writing-plans 与 executing-plans，直接执行已明确的范围。

## 设计和验收

复用 8765 工作台认证、AirflowClient 和现有 Compose。新增 `/skills` 页面与 `skill_experiment` DAG。Airflow 写入共享目录队列，Windows 单一执行桥调用冻结 F 运行器，保留 Windows Ollama 实时日志和原始模型配置。Airflow 以 reschedule sensor 等待并继续核验与发布，所有结果使用同一 job_id 关联。

采用共享目录可复用当前 Docker 挂载，保留本机模型与源路径。容器直接执行需要迁移模型日志和冻结路径；额外 HTTP 服务需要增加端口及认证。当前选择共享目录。

页面支持原完整需求或用户编辑需求、100/166 候选、本地或显式确认费用的 DeepSeek。现场验收使用本地模型。新运行独立归档，原始十次统计作为历史分组呈现。自动评估与人工六项复核分别显示，失败与历史证据均可查看下载。下载仅允许该运行实际文件及哈希匹配的最终产物。主机桥展示心跳和队列状态，进程崩溃/重试保留原始请求及部分产物。
