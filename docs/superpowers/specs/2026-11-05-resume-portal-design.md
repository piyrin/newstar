# 简历工作台与模板改进

用户要求：第一/第三版式差异不足；采用常用版式；触发后网页人工审阅与导出，不再每次输命令；显示结果位置和下载。

沿用 Airflow 整理/导出两个 DAG，新增常驻本机 8765 工作台作为统一入口。网页选择材料案例、岗位并触发，显示运行状态，整理完成进入审阅页。审阅后明确点击“确认并导出”，服务端验证批准、调用导出 DAG，展示进度、错误、Word/PDF 下载、全部页面预览及最终验收按钮。物理输出仍在 resume_workspace/outputs，页面给出目录。保留原 CLI 和分离 DAG，避免 Worker 等待人工输入。

工作台通过 Docker Compose 自动运行，127.0.0.1 发布端口；浏览器同源自定义头获取临时会话令牌，API 必须携带 Bearer，校验 Host/Origin，不支持跨域。下载仅允许本案例已成功检查产物，阻止路径越界和未检查/被篡改文件。

classic经典细线、minimal简洁文本、technical技术分栏保留标识；网页示意和Word结构对应，真正分页以PDF为准。只借鉴 Harvard/MIT 职业中心示例的通用布局，不宣称官方原版。

验收：无令牌/跨站拒绝，准备与导出通过真实 Airflow，未确认导出拒绝，轮询可恢复，正确下载且防越界，三套正文一致布局不同，中文PDF逐页看图；不把测试虚构确认当成用户真实确认。
